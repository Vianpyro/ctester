# Motivations

Les profils sont des motivations simultanees, non des diagnostics permanents. L'interface ne classe pas un etudiant en «type».

| Motivation | Reponse | Limite |
| --- | --- | --- |
| Competiteur | mode classe, record personnel | opt-in, jamais dominant |
| Collectionneur | accomplissements/cosmetiques | pas de rarete punitive |
| Explorateur | contextes et defis optionnels | aucun secret requis |
| Social | objectif de classe | pas de partage de solutions |
| Maitrise | skill tree, verification, recommandations | pas de fausse precision |
| Perfection | qualite/record lorsque mesurable | erreurs toujours valorisees |
| Autonomie | choix de contexte et parcours | recommandations non obligatoires |
| Contextuel | probleme d'ingenierie utile | competence C equivalente |

La personnalisation est une preference explicite, modifiable et privee par defaut; elle n'infere ni programme d'etudes ni capacite.
